## 2. Project Title

Number Guessing Game

Ticket Price Calculator 

## 3. Project Description

a program that calculates the total ticket price for an event. Ticket prices are based on the visitor's age

---

## 4. Objectives

This project is designed to apply the following programming concepts:

- Variables
- Data types
- Operators
- Conditional statements
- Loops
- Algorithms
- JavaScript

---

## 5. Input

The program receives:

The number of tickets — the number of tickets purchased by the customer.
The age of each visitor — the age of each person purchasing a ticket

---

## 6. Process

The program compares the player's guess with the target number.

If the guess is:

- Too high → the program provides a "too high" message
- Too low → the program provides a "too low" message
- Correct → the player wins

---

## 7. Output

The program displays:

-The ticket price for each visitor based on their age
-The total number of tickets purchased
-The total price of all tickets
-A summary of the ticket purchase
